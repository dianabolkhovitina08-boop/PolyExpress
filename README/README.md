# Polyexpress
**Polyexpress** — это веб-приложение для отслеживания общественного транспорта. 
Пользователь выбирает нужную остановку и видит точное время прибытия ближайшего автобуса в реальном времени. Сервис работает в разных городах и помогает быстро сориентироваться в расписании междугородних рейсов.
## Основная функция
Удобный веб-сервис, который избавляет от ожидания на остановках. Пользователь указывает свой город и остановку, а система уведомляет его о том, через сколько минут подъедет нужный автобус. Идеальное решение для поездок в суровую погоду.
